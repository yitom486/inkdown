# 书架（阅读库）

> **计划状态**: `pending`  
> **创建日期**: 2026-08-29  
> **最后更新**: 2026-08-29  
> **目标版本**: **v0.3.x**  
> **目标**: 为电子书（及可选 Markdown）提供「书架」总览：续读、进度、收藏管理；提升阅读器开屏体验，**不替代**工作区文件树  
> **优先级**: 低于 v0.1 发布稳定、v0.2 ACP 主路径；与 [Markdown 旁注与批注](./2026-08-29-Markdown旁注与批注.md) 同属 v0.3 体验向，可并行或先后  
> **关联**: [电子书阅读支持](./2026-08-28-电子书阅读支持.md) · [阅读标记与批注](./2026-08-28-阅读标记与批注.md) · [GitHub 发布与版本路线](./2026-08-29-GitHub发布与版本路线.md)

## 产品定位

| 是 | 不是 |
|----|------|
| 个人收藏夹 / 续读入口 | Calibre 式全盘书库扫描与元数据中心 |
| 进度 + 封面（或图标）一眼扫 | 替代「打开文件夹 / 工作区树」 |
| 让开屏更有「书房」感 | v0.1 / v0.2 的阻塞项 |

**必要性**：锦上添花。书少时最近文件够用；书一多、跨目录时，书架会明显更舒服。价值在体验与品牌，不在「有没有也能读」。

---

## 与现有能力的关系

| 已有 | 书架如何复用 |
|------|----------------|
| `recentFiles` | 可作「最近打开」分区；不自动等于书架条目 |
| `reading-progress` | 展示进度条 / 百分比 / 页码章节 |
| `reading-marks` | 可选角标「有批注」；点击进书 |
| 欢迎页 | 书架可替换或并入欢迎页主区域 |
| 工作区树 | 保持文件系统真相；书架只存「我关心的路径」 |

## 推荐形态（分阶段）

### 阶段 A — 轻量书架 MVP（v0.3 必做）

**用户故事**：打开应用 → 看到「在读」卡片列表 → 一点续读；可从当前打开的书「加入书架」或「移出」。

| 项 | 设计 |
|----|------|
| 条目来源 | ① 用户手动「固定到书架」② 可选：有阅读进度的文件自动出现在「最近在读」（可关闭） |
| 展示字段 | 文件名、格式徽章（EPUB/PDF/MOBI/AZW3）、进度、最近阅读时间 |
| 封面 | **MVP 不做真实封面**；用格式图标 + 色块即可 |
| 存储 | `userData/bookshelf.json`（主进程）；IPC + `Result`；Query 拉列表 |
| 失效路径 | 打开失败 → 提示文件不存在 → 可「从书架移除」 |
| UI | 欢迎页 / 独立「书架」视图（网格或列表可切换） |

### 阶段 B — 分组与管理（v0.3 可选）

- 状态：在读 / 想读 / 读完（用户手动标）  
- 排序：最近阅读、书名、进度  
- 搜索过滤  
- 拖拽排序（可选）

### 阶段 C — 封面与元数据（v0.3 末或 v0.4）

- EPUB/MOBI 封面提取缓存（注意体积与隐私，仅本地）  
- PDF 首页缩略图（成本更高，可后置）  
- 显示书名（从元数据，fallback 文件名）

### 明确不做（本计划范围）

| 不做 | 原因 |
|------|------|
| ❌ 全盘 / 递归扫描「所有电子书」建库 | 慢、权限吵、像另一类产品 |
| ❌ 在线书源 / 下载商店 | 与本地阅读器定位不符 |
| ❌ 云同步书架 | 复杂度高；日后再议 |

## 技术草图（阶段 A）

```
shared/types/bookshelf.ts          # BookshelfEntry DTO
electron/services/bookshelf-service.ts
IPC + preload + src/api/bookshelf-api.ts
src/hooks/useBookshelf.ts          # Query + mutations
src/components/library/…           # BookshelfView、BookCard
欢迎页 / ActivityBar 入口
```

约束：

- 渲染进程不直接 `fs`；路径存在性检查走主进程  
- 进度只读 `reading-progress` store / 或其持久化快照，**不复制一份进度真相**  
- UI 偏好（网格/列表）可用 Zustand persist
