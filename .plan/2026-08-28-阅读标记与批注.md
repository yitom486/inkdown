### 阶段 E：导出 Markdown（后续）

产品侧一键导出，**不经过 Agent / MCP**。数据复用 `collectHighlightPassages`（书签默认不进）。

#### 导出选项（两维）

| 内容类型 | 范围 |
|----------|------|
| **批注** | 当前章 / 全书 |
| **重点**（纯高亮） | 当前章 / 全书 |
| **综合**（重点 + 批注） | 当前章 / 全书 |

UI 可用「内容类型」+「本章 / 全书」两个选择，不必做满 6 个按钮。  
**无内容的叶子章节不写**。有笔记的祖先标题仍输出（只为保留层级）。章内按阅读顺序。

#### 正文格式

条目之间用 `---` 分隔；目录层级映射为 Markdown 标题（章 `##`、节 `###`、小节 `####`，最多六级）。无笔记的叶子不写；若子级有笔记，仍保留空的祖先标题以维持层次。

**批注**（`kind: note`）：

```markdown
这里是我的批注，可当 Markdown 写。

> 书中划出的原文
```

**重点**（仅高亮、无批注）：

```markdown
**重点**

> 书中划出的原文
```

**重点 + 批注**（`kind: highlight` 且有 `note`）：

```markdown
**重点**：这里是挂在重点上的批注

> 书中划出的原文
```

**综合**：同一阅读顺序混排；块间 `---`。  
同章/同页内，摘录完全重叠或重叠度 ≥ 80%（一方包含另一方，较短/较长）时，**合并为一条**：取最长摘录；若其中有批注则输出批注块（重点参与合并时用 `**重点**：` 前缀）+ `>` 最长引用。

#### 建议文件名

- 全书：`{短书名}-{yyyyMMdd-HHmm}.md`
- 本章：`{短书名}：{短章名}-{yyyyMMdd-HHmm}.md`（全角 `：`）
- **短书名**：去扩展名 → 去掉 `(z-library…)` 等下载站括注 → 若有 `：`/`:` 副标题只取主标题 → 再截断（最多 25 字）
- **短章名**：安全化后截断（最多 36 字）
- 日期时间默认即可避免重名；若同秒冲突再追加 3 位随机（如 `a7k`）

#### 统一管线（三端共用）

```
list marks → 按内容类型过滤 → resolveChapter(mark) → 按章分组（跳过空章）→ 拼 Markdown → 另存为
```

`resolveChapter` 可插拔；导出 UI / 模板 / 排序只写一套：

| 格式 | `resolveChapter` | 交付 |
|------|------------------|------|
| EPUB | `anchor.href` ↔ TOC | **E1** |
| MOBI / AZW3 | `anchor.chapterId` ↔ TOC | **E1** |
| PDF | `anchor.page` ↔ outline；无目录降级在 PDF 解析器内 | **E2** |
