## 文件命名


- **计划名称**：简短中文描述，词间用连字符

## 状态标记

### 计划级（文档顶部元信息）

```markdown
> **计划状态**: `pending` | `in-progress` | `done` | `cancelled`
```

### 任务级（每条 checklist）

```markdown
- [ ] **[pending]** 任务描述
- [ ] **[in-progress]** 任务描述
- [x] **[done]** 任务描述 — 2026-08-28，`commit-hash`
- [x] **[cancelled]** 任务描述 — 原因说明
```

| 标签 | 含义 |
|------|------|
| `[pending]` | 待开始 |
| `[in-progress]` | 进行中（同一时间建议只有一个） |
| `[done]` | 已完成 |
| `[cancelled]` | 已取消 |

## 更新规则

1. **开始任务**：标签改为 `[in-progress]`，更新「最后更新」日期
2. **完成任务**：勾选 `[x]`，标签改为 `[done]`，补充日期与 commit
3. **计划收尾**：全部任务 `[done]` / `[cancelled]` 后，计划状态改为 `done`
4. **新计划**：新需求优先追加到已有路线图；范围独立时再新建日期文件
