## 状态标记说明

每条任务使用 `- [ ]` / `- [x]` 勾选框，并在任务名前标注状态标签：

| 标签 | 含义 |
|------|------|
| `[pending]` | 待开始 |
| `[in-progress]` | 进行中 |
| `[done]` | 已完成 |
| `[cancelled]` | 已取消 / 不再做 |

**完成规则**：实现并合并后，将标签改为 `[done]`，勾选框打 `[x]`，并补充完成日期与相关 commit（如有）。

**计划级状态**：当本文件内所有任务均为 `[done]` 或 `[cancelled]` 时，将文首「计划状态」改为 `done`。
