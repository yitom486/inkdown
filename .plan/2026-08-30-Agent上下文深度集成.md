## 架构总览（定稿）

三层职责，**互不抢活**：

```
┌─────────────────────────────────────────────────────────────┐
│ ① 静态 Skill（INKDOWN_STATIC_SKILL）                         │
│    产品介绍 + 规则 + turn-context 格式说明 + 虚拟 fs 工具表   │
│    → 每条 prompt 固定前缀，字节不变，利于 Provider cache      │
├─────────────────────────────────────────────────────────────┤
│ ② 动态 turn-context（拼在【用户消息】前，非系统提示词）         │
│    轻量：当前文件、阅读位置、是否刚换文件                       │
│    → 换文件必带；每 N 轮（默认 5）带一次；来自内存快照          │
├─────────────────────────────────────────────────────────────┤
│ ③ 按需虚拟 fs（ACP fs/read_text_file）                       │
│    重内容：完整 TOC、章节正文、视口、选区、检索                 │
│    → Agent 需要时再拉；Client 从内存序列化，【不高频写盘】       │
└─────────────────────────────────────────────────────────────┘
```

**明确不做**：

- MCP / 用户可配 MCP UI  
- 让 Codex 解析 `.epub/.pdf/.mobi` 二进制  
- 滚动/选区高频写工作区文件  
- 在静态 Skill 里塞进度、路径、TOC（打穿 cache）  
- 解析结果多处复制；**内存一份**，turn-context 与 fs 虚拟读 **现序列化**

## ① 静态 Skill

**文件**：`resources/agent/inkdown-skill.md`（或 TS 内联常量）

**内容仅含**：

1. Inkdown 是什么（Markdown 编辑 + EPUB/PDF/MOBI 阅读）  
2. 规则：禁止 read 电子书二进制；信任 `[inkdown-turn-context]` 为客户端快照  
3. `[inkdown-turn-context]` 块格式说明（可能出现 / 含义 / `documentChanged`）  
4. **虚拟 fs 工具表**（路径 = API 名，见③）  

**不含**：workspace 路径、当前书名、进度数字、TOC 正文。

### Prompt 组装

```typescript
// session/prompt ContentBlock[]
[
  { type: 'text', text: INKDOWN_STATIC_SKILL },           // 恒定 → cache
  ...(turnContextBlock ? [{ type: 'text', text: turnContextBlock }] : []),
  { type: 'text', text: userMessage },
  // chips: resource_link / image …
]
```

`turnContextBlock` 可选；Skill 块 **始终**存在且不变。

## ② 动态 turn-context

### 触发条件（满足任一即附带）

| 触发 | 说明 |
|------|------|
| **`documentChanged`** | 用户切换打开文件（MD ↔ EPUB、换书、关文件后再开） |
| **每 N 轮用户消息** | 默认 **N=5**，防长对话遗忘；线程内计数，仅计 user 发送 |
| （Phase 2 可选）**`navigationJump`** | 同文件内跨章幅度大（如 flatIndex 变且非连续滚动） |

**不**每轮都带——多数轮次仅静态 Skill + 用户话，节省 token。

### 块格式

```text
[inkdown-turn-context]
{"documentChanged":true,"activeDocument":{"path":"…","kind":"epub","title":"…"},"reading":{"percent":12.4,"currentLabel":"自序","previousLabel":"前言","nextLabel":"引言"}}
[/inkdown-turn-context]
```

### Phase 1 字段（刻意保持小）

| 字段 | 说明 |
|------|------|
| `documentChanged` | 本回合是否刚换文件 |
| `activeDocument.path/kind/title` | 当前打开文件 |
| `activeDocument.sizeBytes` | 可选 |
| `reading.percent` | EPUB/PDF 进度 |
| `reading.currentLabel` / `previousLabel` / `nextLabel` | 导航 |
| `reading.pdfPage` / `pdfTotalPages` | PDF 专用 |

**Phase 1 不含**：完整 TOC、章节正文、选区（留给虚拟 fs 或 Phase 1.5）。

### TOC 策略

| | turn-context | 虚拟 fs |
|---|--------------|---------|
| **Phase 1** | **不带**完整 TOC | — |
| **Phase 1.5** | 可选 `tocTopLevel`（仅一级，≤10 条） | `fs/read .inkdown/agent/toc.json` 完整目录 |
| **原则** | 轻、常变、提醒 Agent「你在哪」 | 重、偶要、Agent 按需拉 |

### 数据来源

- `reader-navigation-store`、`filePath`、`readerDocumentKind`、Editor outline（MD）  
- **`buildTurnContext()`** 纯函数 + hook；**不写盘**  
- 发送路径：`useAcpSession` / `AgentComposer` submit 时调用

## ③ 按需虚拟 fs（ACP 内置，非 MCP）

Agent 通过 codex-acp 调用 **`fs/read_text_file`** → Inkdown `client-handlers` / `acp-fs` 拦截 **虚拟路径** → **IPC 问前台渲染进程** → 从 **内存 cache/store** 序列化返回 `{ content: string }`。

**不是**必须先在工作区落盘；磁盘 cache（`.inkdown/cache/*.txt`）仅 Phase 1.5+ **可选**，大章或跨重启时用。

### 虚拟路径表（Skill 内文档，路径相对 cwd）

| 工具名 | 虚拟路径 | 返回内容 | 阶段 |
|--------|----------|----------|------|
| `inkdown_focused_state` | `.inkdown/agent/focused.json` | 前台窗：文档 + 阅读态 + 选区（JSON） | 1.5 |
| `inkdown_toc` | `.inkdown/agent/toc.json` | 完整 TOC（内存 `units[]`） | 1.5 |
| `inkdown_viewport` | `.inkdown/agent/viewport.txt` | 视口 ±200 字纯文本 | 1.5 |
| `inkdown_chapter` | `.inkdown/agent/chapter.txt` | 当前章已解析正文（截断） | 1.5 |
| `inkdown_chapter_at` | `.inkdown/agent/chapter/{flatIndex}.txt` | 指定章正文 | 2 |
| `inkdown_search` | （带参，见 Spike） | 本书内检索 snippets | 2 |

**拒绝**：对 `.epub/.pdf/.mobi` 真实二进制 path 的 read → 返回 hint「请读虚拟路径或依赖 turn-context」。

### 带参检索（Phase 2，仍优先非 MCP）

- 优先 **ACP `_inkdown/search` extMethod**  
- **不**默认内置 MCP；仅 ext 不通再 Spike

| 阶段 | 做法 |
|------|------|
| **Phase 1** | turn-context 与虚拟 fs 均取自 **BrowserWindow focused** 渲染进程 |
| **Phase 1.5** | 虚拟读 `manifest.json` 列出各窗；`windows/{windowId}.json` 各窗快照 |
| **已知限制** | ACP 主进程单例、session 事件广播全窗——聊天 UX 独立议题，本计划不阻塞 |

同工作区、不同工作区：虚拟 fs **不依赖**共享写盘文件，冲突面小。

## 风险

| 风险 | 对策 |
|------|------|
| Codex 忽略 turn-context | Skill 写明语义；`documentChanged` 强提示 |
| Agent 不主动 fs 读 TOC | turn-context 已给 currentLabel；Skill 指引问结构时读 toc.json |
| 虚拟 fs IPC 延迟 | 快照纯内存，目标 <50ms |
| 全局 ACP 多窗串线 | Phase 1 仅 focused；1.5 manifest |
